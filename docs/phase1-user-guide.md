# CodexQuotaShare — Windows 使用说明

## 运行

完整解压 ZIP 到可写目录，运行 CodexQuotaShare.exe。无需额外 .NET Runtime。默认进入托盘；点击打开，右键可刷新、暂停/恢复通知、打开设置或退出。关闭窗口仍在后台运行。

本机应安装并登录 Codex。自动查找已知原生安装位置、Windows Codex 包和 PATH；失败时在设置选择本机原生 codex.exe。无需输入 OpenAI Token 或 API Key。

公共服务尚未上线，此候选包的高级连接设置需要一个兼容 Relay 地址。未来正式 Release 内置地址，用户只需创建或加入群组。不要将此候选包当成已上线版本。

## 设备群组

创建群组后把 15 分钟邀请码交给自己的其他电脑。Owner 从设备名称列表中选择目标，设置 1–100% 或 Unlimited，并可重命名、移除设备、转让所有权或生成新邀请码。Member 无法修改限额或账本。Owner 离开前须先转让所有权。换同步地址前先离开原群组。

官方账号周额度与设备估算用量分开显示；Unknown 是缺少可靠归因信号的消耗。限额约为指定的官方周额度百分比，存在同步和计量粒度误差。初次监控前的消耗不回填到设备。

## 通知和本机限制

设置包含开机启动、桌面通知、Soft enforcement、设备名称和诊断日志。任何设备到限额或新周期确认，在线设备显示 Windows 通知。系统禁用通知时仍可从红色警告和群组状态看到限额。

Soft enforcement 默认开启。达到限额后阻止新启动，并关闭同一登录会话中已识别的 Codex CLI/桌面程序，可能中断正在运行的任务。只按精确安装路径匹配，自己的额度观察进程豁免。重置或 Owner 提高限额后解除。断网和重启保留已知限制。管理员、退出本工具或关闭此设置可以绕过；本工具不是防篡改平台。增强防火墙限制未启用。

## 数据与离线

本地每 20 秒汇总活动，官方额度监听更新并每 60 秒补充读取。CODEX_HOME 自定义位置生效。仅分析 token_count 的计数与时间，不保存内容。断网时保留缓存并显示过时状态，重连以服务端完整快照修复本地状态。超过 5 分钟的待发信号不参与当前归因。

设置、DPAPI 身份、额度缓存、活动游标、统计、待发汇总和群组快照保存在应用目录 data/。不要把已使用的 data/ 目录当作安装包分发。日志仅固定状态码和时间。开机启动设置仅在用户勾选并保存后写当前用户启动项。

## 演示

~~~powershell
.\CodexQuotaShare.exe --demo
~~~

演示只用合成数据，不读取账号、会话或已有设置，不执行通知注册、进程关闭或开机启动修改。
